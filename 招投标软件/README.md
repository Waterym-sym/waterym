# 招投标软件（Intelligent Bidding Tool）

## 1. 项目是干什么的

**智能投标 / 标书辅助工具**：上传 PDF/Word 招标文件 → 信息解析 → 选择商务标书模板 → 生成标书 → 合规检查 → 导出 Word。前端（Vue/Element Plus）+ 后端（Spring Boot）联通完整演示流程，用于提升编标效率。

## 2. 我在这个项目负责了什么

- 前后端联调与本地启动链路（上传目录、CORS、代理）。
- 工作台到导出下载的各节点页面与流程打通。
- 解析结果可编辑、模板选择、合规检查等演示能力实现。

## 3. 实际解决了哪些问题

- 编标前期从招标文件**摘信息费时、易漏项**。
- 模板套用与合规检查缺少辅助工具。
- 需要可演示的端到端产品原型以验证方向。

## 4. 做到了什么程度

- 本地可启动全流程（前端约 3000、后端约 8080）。
- 部分节点仍可用 Demo/模拟数据，适合演示与继续产品化。
- 真实复杂招标文件的解析质量与模板库丰富度待加强。

## 5. 有哪些成果

- Intelligent Bidding Tool 工程与启动说明。
- 可演示的「上传 → 解析 → 生成 → 检查 → 导出」路径。

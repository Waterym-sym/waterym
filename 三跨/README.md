# 三跨（跨铁路 / 跨高压等业务系统）

## 1. 项目是干什么的

支撑**跨铁路、跨高压等「三跨」施工/管理业务**的 Web 系统：含 Vue 前端独立工程（`sankua-frontend`）、Java 管理端（`sk-java-admin`）以及参数抽取、提示词与 AI 智算相关试验材料，服务专项跨越场景的信息录入、流程与展示。

## 2. 我在这个项目负责了什么

- 前端独立工程拆分与可本地启动维护（自 `sankua_web` 完整拷贝演进）。
- 与后端/网关联调配置（环境变量、代理、各测试构建产物）。
- 三跨相关提示词、参数抽取试验与跨铁路/跨高压资料整理。

## 3. 实际解决了哪些问题

- 三跨业务信息分散，**缺少统一前端入口与可维护工程边界**。
- 原前端与仓库其它目录耦合，不利于单独交付与联调。
- 部分参数需从文档中抽取，人工整理成本高，探索 AI 辅助。

## 4. 做到了什么程度

- `sankua-frontend` 可独立 `npm run dev` / 多环境 build。
- Java 管理端与既有业务能力在推进、对接中。
- AI 参数抽取等为增强能力，视场景选用。

## 5. 有哪些成果

- 自包含三跨前端工程与 Java admin 工程。
- 跨铁路、跨高压、提示词与试验目录资产。
- 前后端分离后的联调与部署说明基础。

# 基于录屏提炼（AI 操作流程提炼与复现验证）

## 1. 项目是干什么的

探索用多模态大模型从**电脑录屏**中提炼操作步骤（抽帧 / 原视频提示词等路径），评估 Gemini、Qwen 等模型在操作描述与流程结构化上的效果，并形成技术路线与验证报告，服务于「技能学习 / 操作复现」类平台方向（含 Computer_Skill_Learning_Platform 相关材料）。

## 2. 我在这个项目负责了什么

- 录屏样本组织与多组提示词（Prompt A/B/C、抽帧 vs 原视频）设计。
- 多模型输出对比测试与结果归档。
- 技术验证报告 / 技术路线文档整理。

## 3. 实际解决了哪些问题

- 内部软件操作培训依赖师傅带教，**难沉淀成可复用步骤说明书**。
- 需先行验证：录屏 → AI → 结构化步骤是否在效果上说得通。
- 为后续自动生成教程/RPA 辅助提供依据。

## 4. 做到了什么程度

- **技术验证阶段**：多视频、多模型、多提示词对比已跑通。
- 尚未形成稳定的生产级自动复现产品（步骤执行器/权限安全等未完整产品化）。

## 5. 有哪些成果

- 测试集结果目录（各 video × 模型输出）。
- 《AI 录屏流程提炼技术验证报告》与技术路线文档。
- 可复现的实验方法与提示词资产。

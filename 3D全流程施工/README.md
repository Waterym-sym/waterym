# 3D 全流程施工（输电线路排位 / 仿真）

## 1. 项目是干什么的

输电线路**排位与施工可视化**方向：基于 Vite + React + Konva（2D）+ R3F（3D）的 tower-demo，支持主塔/耐张/跨越物放置、弧垂与工程参数、2D 断面与 3D 场景联动；并结合开源 Editor（Pascal）的编辑器架构能力，探索「可编辑的全流程施工」产品形态；另有 Python 侧公式/服务试验。

## 2. 我在这个项目负责了什么

- 2D/3D 场景交互（选择、框选平移、改位、测量坐标等）开发与打磨。
- 工程参数面板、弧垂正视/俯视测量与布局滚动等体验问题修复。
- Editor 与 tower-demo **能力对照与结合方案**文档。
- 与计算权威性（后端/规范公式）边界的技术判断。

## 3. 实际解决了哪些问题

- 纯二维图纸难表达空间关系与跨越工况，**沟通成本高**。
- 排位过程频繁调参，需要更直观的放置预览与双视图。
- 编辑器通用能力（撤销、工具态、增量更新）与电力领域公式尚未统一产品化。

## 4. 做到了什么程度

- 演示级产品可玩：放置、参数、2D/3D、部分测量与编辑工具已落地。
- 公式多为演示级，正式产品需接行业规范或智算后端。
- 与 Editor 的结合仍以架构/交互借鉴为主，未完全 monorepo 合并。

## 5. 有哪些成果

- tower-demo / tower-demo-1 等可运行前端。
- 《Editor 与 tower-demo 功能结合说明》。
- 一批可用性交互（框选平移、测点、canvas 布局等）沉淀。

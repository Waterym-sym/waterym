# 送电智算管理平台（智算）

## 1. 项目是干什么的

面向送电/架线施工的**专业计算与项目管理桌面平台**：将弧垂、连续爬坡档让线值、架线线长、地锚受力、封网式跨越等计算模块做成可授权使用的软件（Flask + WebView / 可打包 exe），并配套管理后台做激活码与版本授权。

## 2. 我在这个项目负责了什么

- 核心计算模块的工程化落地（参数录入、结果展示、模板与项目管理串联）。
- 桌面端启动/许可流程（试用以至企业版功能分级）。
- 管理后台侧激活码、硬件指纹绑定、授权文件相关能力联调。
- 使用说明、进度汇报类文档与交付包整理。

> 若与同事分工不同，请按实际修改本段「负责」表述。

## 3. 实际解决了哪些问题

- 现场/技术员仍依赖零散表格与经验估算，**计算口径不统一、难复用**。
- 缺少可管控发放的计算软件（试用期、版本权限、机器绑定）。
- 项目管理与计算结果脱节，难以形成「项目 → 计算 → 导出」闭环。

## 4. 做到了什么程度

- **可用产品形态**：支持一键启动 / exe 使用；免费核心计算 + 标准/专业/企业分级。
- 授权体系（在线/离线激活、RSA 校验、使用统计）已形成闭环方案。
- 计算算法与界面仍可持续校准、扩展（行业标准深化、批量处理等）。

## 5. 有哪些成果

- 送电智算管理平台主程序与管理后台代码。
- 功能开发进度汇报、使用说明、相关计算说明与演示材料。
- 可对外演示/对内发放的授权版安装包能力。

# 中控管理平台

## 1. 项目是干什么的

基于 **Spring Cloud Alibaba** 的中控类微服务父工程：统一 **Gateway 网关**、**Nacos** 注册与配置、公共模块，以及人员排班（Personnel Scheduling）等业务服务，作为公司侧「中控 / 调度」类系统的技术底座。

## 2. 我在这个项目负责了什么

- 网关、公共模块、Nacos 配置模块搭建与联通。
- 服务拆分与端口/启动类规范。
- 人员排班等业务服务接入中控体系。
- 模块 README 与架构说明维护。

## 3. 实际解决了哪些问题

- 多业务系统各自暴露端口，**缺少统一入口与配置中心**。
- 后续新服务难以按同一套治理规范接入。
- 需要为排班等中控能力预留可扩展微服务位置。

## 4. 做到了什么程度

- 父工程 + Gateway + Nacos Config + 公共模块 + 排班等模块骨架可用。
- 技术栈固定：Spring Boot 2.7、Spring Cloud 2021、SCA 2021、Java 8。
- 业务功能广度与生产运维配套（监控、鉴权细化等）可持续增强。

## 5. 有哪些成果

- `centralsystemparent` 工程与架构文档、API 说明。
- 可复用的中控微服务脚手架。

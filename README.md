## 二、工作期间主线（按业务域）

### 1. 电力施工数字化与智能计算
- **智算**：把弧垂、架线长、地锚受力、封网跨越等计算做成可授权的桌面产品。
- **3D 全流程施工**：在二维断面 + 三维场景里做排位、跨越、交互编辑，为「看得见的施工设计」铺路。

### 2. AI 赋能方案编制与审查
- **指挥中心 AI**：方案智能生成、审查、知识与模板驱动的多版本研发。
- **审查**：把审查能力工程化为前后端可联调系统（完整性、合规、模型调用等）。

### 3. 现场装备与检测闭环
- **工器具检测系统**：从任务接收、班组分配到执行与报告的微服务闭环。
- **RFID / 检测报告**：现场扫码盘点与合格证开具，贴近装备中心实际作业。

### 4. 工程业务与中台能力
- **三跨**：跨铁路、跨高压等专项业务前端与管理后台。
- **中控管理平台**：统一网关、配置与排班等中控微服务底座。

### 5. 提效工具与前沿探索
- **招投标软件**：招标文件到商务标书的半自动流水线。
- **基于录屏提炼**：多模态模型抽操作步骤的可行性验证。
- **开源项目**：吸收编辑器、Agent、若依等能力到业务系统中。

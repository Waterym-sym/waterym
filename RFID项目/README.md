# RFID 项目（装备中心盘点 / 查询）

## 1. 项目是干什么的

基于 **UniApp + PDA 原生插件** 的 RFID 应用族：设备初始化与读卡、标签查找、装备中心业务页面，以及 OCR + RFID 查询验证等试验版本，用于现场扫码/读标签盘点与资产核对。

## 2. 我在这个项目负责了什么

- PDA（如 Pda6000）原生插件接入与读写标签流程调试。
- 多版本 UniApp 业务页（查询、盘点、验证）开发与接口联调。
- OCR 识别与 RFID 结果交叉验证的原型验证。
- 接口文档与多包版本对照整理。

## 3. 实际解决了哪些问题

- 装备数量大，**纯人工点检效率低、易漏**。
- PDA 硬件能力需进业务 App，才能现场读 RFID。
- 标签损坏或无法读时，需要 OCR 等兜底核对手段。

## 4. 做到了什么程度

- 多版本包（含装备中心 uniapp、gaisite-rfid、rfid_find、OCR 验证等）可在真机联调。
- 核心读卡/停读/释放设备链路已通。
- 业务字段与后端接口随装备中心主系统持续对齐中。

## 5. 有哪些成果

- 可安装的 UniApp PDA 工程多迭代版本。
- RFID 对接接口文档。
- OCR + RFID 查询验证原型。

# 审查（施工方案智能审查）

## 1. 项目是干什么的

独立工程化的**施工方案审查系统**：前端 `review-standalone-vue` + 后端 `dp_construction_scheme_system`（Spring Boot），对接大模型做完整性、合规等内容审查，支撑指挥中心 AI 中「审查」能力的落地与联调。

## 2. 我在这个项目负责了什么

- 前后端约定与联调（API 基址、健康检查、审查接口）。
- 审查流程相关服务与前端结果展示的问题定位（含模型/网络异常误报类问题）。
- 提问清单、审查规则与界面体验迭代。

## 3. 实际解决了哪些问题

- 方案审查**缺少统一的数字化入口**，结果难沉淀。
- 人工全文审阅耗时长，需要按章节/规则自动指出问题与修改建议。
- 前后端与模型调用链路需要可调试、可替换的工程骨架。

## 4. 做到了什么程度

- 前后端骨架与审查主流程可用；后端可扩展业务接口与 MySQL 持久化。
- 已能跑通「上传/提交 → 模型审查 → 前端展示原因与建议」路径。
- 异常归因、规则精度、批处理与权限体系仍可加强。

## 5. 有哪些成果

- 可独立运行的审查前后端工程。
- 审查提问清单与联调经验（含 DNS/模型不可达等线上问题排查）。
- 与指挥中心 AI 多版本方案材料对齐的能力沉淀。
